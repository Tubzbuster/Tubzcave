# Tubzcave source

The site files in the repo root are generated from this folder.
Run `python3 src/build.py` after editing, then commit the regenerated files.

- `profiles.py`: edit your DragonFable / Neopet / WoW character details here
- `index.tpl.html`, `style.tpl.css`, `profiles.css`, `mobile.css`: page and styles
- `build.py`: builds `index.html`, `about.html`, `mimi.html`, `style.css`, `site.js` into the repo root
